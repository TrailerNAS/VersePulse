# Overview

VersePulse is a desktop companion application for Star Citizen that provides real-time telemetry, session tracking, diagnostics, and gameplay insights.

VersePulse **does not** inject into the game, read memory, modify game files, or automate gameplay.

All information is obtained from Star Citizen's publicly available Game.log and standard Windows APIs.

# Building

Requirements

- Visual Studio 2022
- .NET 8 SDK
- Windows 10 or newer

Clone

```bash
git clone https://github.com/TrailerNAS/VersePulse.git
```

Open

```
src/VersePulse/VersePulse.sln
```

Build

```
Build → Build Solution
```

Run

```
F5
```
